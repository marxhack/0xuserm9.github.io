This is my first post. I'll write about anything here: bug bounty writeups,
security research, tools I build, my journey learning all of this, or whatever
else comes to mind. Mostly I'm writing it down for myself, because I forget
things I already figured out, and reading my own notes later is faster than
working them out a second time. If it ends up useful for someone else, good.
No schedule, I'll just post when I have something worth posting.
